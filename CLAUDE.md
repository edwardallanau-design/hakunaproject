# guild-website

Next.js 16 + Payload CMS site for the guild.

## Agent skills

### Project ledger

`.scratch/LEDGER.md` is the durable record — an append-only **Shipped** log of what was built and why, plus the **Open** backlog. Read it before starting work, and add to it when something ships or a known issue is found. `docs/superpowers/` was retired on 2026-08-04; its content was migrated here.

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature-slug>/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
